Vexflow — dictation that runs on your own API keys

Hold a key, talk, let go. The text appears wherever your cursor is: browser, terminal, chat, email.

Your audio goes from this Mac straight to Deepgram under your own account. There is no Vexflow server, no account to create, and no telemetry.

This installer will:

  • Put Vexflow in your Applications folder
  • Build the Python environment it runs in, in your Library folder
  • Set it to start when you log in

After installing, Vexflow opens a short setup guide: paste a Deepgram API key, then allow microphone and accessibility access.

Everything it installs can be removed again later: Settings → Permissions → Remove Vexflow.
