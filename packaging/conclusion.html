Vexflow is running

Look for the sail icon in your menu bar. A setup window should be open; if it is not, choose Setup Guide from that menu.

  1. Paste a Deepgram API key — Get key opens the signup page
  2. Allow microphone access
  3. Allow accessibility access
  4. Restart Vexflow, so macOS applies that last permission

Then hold your push-to-talk key, say something, and let go.

Vexflow keeps no log unless you ask it to. If something needs diagnosing, switch one on in Settings → Permissions; it records timings and errors, never what you said.

To remove Vexflow: Settings → Permissions → Remove Vexflow.
